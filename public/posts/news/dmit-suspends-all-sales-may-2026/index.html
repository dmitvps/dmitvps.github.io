过去数周内，经常有站友反馈 DMIT 官网的多款热门套餐长期处于 “Out of Stock” 状态。这种大面积且持续的断货不仅让有扩容需求的老客户感到无奈，也让不少慕名而来的新用户无从下手。

今天 DMIT 官方终于在近日打破沉默，罕见地发布了一则紧急公告，正面回应了全线缺货的现状，并做出了一个出乎所有人意料的决定：暂停所有产品的销售，以最大程度地减少对现有客户的影响。

为了让大家能清晰掌握各大机房的最新动向，接下来我们将针对这则通知的核心内容进行逐项拆解。

DMIT 官方通知核心要点速览#

对于绝大多数正在等待补货或者关注网络状态的买家来说，官方公告虽然字数不多，但信息量极大。

DMIT 在通知中并没有敷衍，而是直白地向用户交代了当前制约其继续销售的两大物理瓶颈。为了帮助大家在几秒钟内快速抓住重点，站长在这里将复杂的官方表述梳理为以下几个最核心的要点。

  • 全球 IPv4 地址遭遇合同进度限制：目前所有机房都处于 IP 资源极度短缺的状态。虽然新购的 IPv4 地址已经在走合同过户流程，但由于执行进度受限，无法给出确切的上线交割时间。
  • 洛杉矶机房机位与电力达到极限：作为核心的 LAX 机房面临严重的机柜空间和电力供应瓶颈。尽管新服务器硬件已经运抵现场，但也必须先解决机位和供电的排期才能上架。
  • 罕见打破常规绕过 IP 预热期：为了缓解极度缺货带来的资源压力，官方明确表示一旦新 IP 到手就会直接投入资源池，这将直接取消以往长达 3 到 6 个月的 IP 预热惯例。

以上三点就是导致 DMIT 做出全面停售决策的根本原因。

不难看出，上游网络供应链的交割延迟与物理数据中心的物理限制，共同造成了这次阶段性的资源断档。由于 DMIT 旗下不同区域机房的硬件储备和网络架构存在差异，对各个区域的具体影响并不相同。

为了让打算入手不同机房的用户有直观的预期，下面我们逐一进行更深度的拆解。

三大核心机房最新扩容进度盘点#

为了让大家对打算入手的机房有一个宏观且直观的预期，站长将官方散落在公告中的零碎信息提取了出来，整理成了下面这份各机房现状对比表，方便大家一眼看懂目前的实际进度。

机房位置当前核心瓶颈最新硬件与网络资源进展恢复销售预期
LAX 洛杉矶缺机柜空间、缺电力、缺存储集群新硬件已运抵现场，正在协调机位供电；新存储集群在途。预计需数周，初期不卖大配置实例。
HKG 香港缺 IP 资源、硬件待组装部署新硬件已到现场，正在进行组装；纯等待新 IP 资源到账。IP 到位后立即恢复销售。
TYO 东京仅缺少可用 IPv4 地址硬件准备充足，完全卡在 IP 合同的交割进度上。属于“随时可能突发补货”的状态。

从这份宏观对比中可以看出，虽然三个机房都受到了停售的影响，但背后的物理瓶颈和恢复所需的时间跨度完全不同。尤其是核心的美国西海岸洛杉矶机房，其内部情况比亚太机房要复杂得多。

接下来，我们分块来详细解读各大机房的具体情况与后续影响。

LAX 洛杉矶机房，新硬件就位但面临存储与大实例限制#

作为 DMIT 最为核心的流量和业务腹地，LAX 洛杉矶机房（特别是主打高端 CN2 GIA 线路的 Pro 系列）这次遇到的阻力最为棘手。公告中明确提到，新购置的硬件设备其实在上周就已经运抵了数据中心。

然而，目前的瓶颈被卡在了 “机柜空间有限” 和 “电力供应紧张” 这两个硬性物理指标上。数据中心落实新的机位并拉好动力电，预计至少还需要数周的排期时间。

更需要注意的是：即使硬件全部上架部署就绪，他们也不会立即恢复大型实例的销售。

这是因为计算节点虽然到位了，但用于支撑大配置实例的 “新存储集群” 目前还在运往数据中心的途中。在计算节点部署完成后，存储集群的安装、分布式调修也需要额外耗费一部分时间。

因此，打算购买大配置、高配置 VPS 的老用户，短时间内可能需要继续等待了。

HKG 香港与 TYO 东京机房，硬件万事俱备只欠 IP 资源#

相比于洛杉矶机房的复杂局面，亚太地区的 HKG 香港和 TYO 东京机房的情况要明朗得多。

香港机房的新硬件和洛杉矶一样已经运抵现场，官方表示将以最快的速度完成这些设备的组装与部署工作。而东京机房在硬件储备上更加充裕，目前完全不需要担心计算和存储能力。

也就是说，制约香港和东京机房复产的唯一阻碍就是 IPv4 地址的交割进度。只要上游的 IP 购买合同执行完毕，新 IP 划入资源池并完成网络广播，这两个机房就能随即在第一时间恢复销售。

对于想入手香港 Pro、东京 Pro 等高端亚太优化线路的站友来说，补货速度会快于洛杉矶。

现阶段用户的入手建议与高品质备选方案#

面对 DMIT 突如其来的全线停售，正在观望的买家和有迫切建站需求的用户不必盲目焦虑。根据官方公告里披露的扩容排期，不同业务时效需求的站友完全可以采取分流处理的应对策略。

  • 不急于部署新业务的用户，建议以静制动：香港和东京机房的硬件底座已经全部就位，唯独在等待 IP 合同交割。由于亚太区域不涉及复杂的机架和存储集群调整，一旦网络资源到账就会瞬间开放销售。
  • 急需稳定美西优化线路的用户，建议果断分流：洛杉矶机房由于面临机位、电力和存储集群的多重扩容，数周内即便恢复销售也是小配置的 VPS，官方也明确表示短期内无法提供大配置实例。

对于属于后者、现阶段特别急需高端优化线路的同学，可以重点考虑将 BandwagonHost（搬瓦工） 作为主力的替代方案。虽然搬瓦工通常会比 DMIT 稍贵一些，但体验并不比 DMIT 差。

特别是搬瓦工招牌的 洛杉矶 DC9 机房，其线路和性能完全可以媲美 DMIT 的 Pro 系列。

站长直达通道： 如果你想继续守候第一手补货资源，可前往 DMIT 官网 保持刷新和关注；若生产环境急需立即部署上线，可直接前往 BandwagonHost 官网 挑选其 DC9 机房。

无论是坚守 DMIT 还是果断转投替代方案，根据自身项目的紧急程度理性消费。

常见问题解答（FAQ）#

为了让大家能彻底吃透这次公告背后的技术细节，站长针对近期技术群和论坛里讨论最激烈的几个核心疑问，整理了以下几个最具代表性的场景问答。

Q1：DMIT 突然全线暂停销售是不是商家准备跑路？#

+

完全不是。

这次全面停售是商家为了保护现有客户体验而做出的决定。DMIT 长期以来主打高端优化线路，由于国内用户需求量极大，导致其物理机房的电力、机位以及极为珍贵的 IPv4 地址库存告急。

如果为了赚钱盲目超售，只会导致现有用户的网络质量整体雪崩。这种 “宁可不卖也不砸招牌” 的决策，反而证明了其在长期运维上的务实与理性。

Q2：公告中提到的新 IP 没有经过预热直接投入资源池会带来什么后果？#

+

在主机圈的常规操作中，新购买的 IP 段通常需要放置在机房 3 到 6 个月进行 “预热”。

这段时间是用来让全球各大运营商逐步收录 BGP 宣告，并优化入站与回程路由的。跳过预热期意味着在头一两周内，部分地区的国内入站流量可能会出现短暂的绕路、延迟飙升或丢包。

Q3：新 IP 的地理位置信息滞后会影响流媒体解锁，甚至报错吗？#

+

大概率会受到短期影响。

因为 IP 库的更新是有周期的，像 MaxMind、IPinfo 或者是 IPIP.net 这类权威数据库。在新 IP 刚刚分配给你的那段时间里，Netflix 等流媒体平台可能依然将该 IP 识别为它曾经所属的旧地区。

Q4：既然洛杉矶机房硬件已经到了为什么官方说还要等上数周时间？#

+

这是因为服务器从运抵现场到真正开机联网，中间隔着数据中心的物理排期。

DMIT 公告里说得很直白，目前的瓶颈在 “机柜空间” 和 “电力供应”。换句话说，服务器现在只能堆在仓库里，必须等机房拉好新的高功率动力电、空出新的机柜机位后才能上架。

此外，由于大配置实例重度依赖的存储集群还在运输途中。

Q5：我手里已经有正在运行的 DMIT 机器会受到影响吗？#

+

对于存量老用户来说，这反而是个好消息。正如前文所说，停止新销售意味着没有新的邻居来抢占机房总带宽和计算资源，你手头正在运行的 VPS 在晚高峰的稳定性甚至可能会有所提升。

你唯一需要注意的就是务必按时续费。
