DMIT 旧版 154 开头 IP 收费调整通知及免费更换指南

近日，DMIT 官方发布了关于 IP 地址租赁策略的重要调整通知。由于全球 IP 成本持续上涨，DMIT 已全面转向自购并独立管理 IP 的模式。

对于目前仍在使用并需要保留旧版 Cogent IP（即 154 开头的 IP 地址）的用户，自 2026 年 12 月 1 日起将面临额外的月度租金补贴费用。本文将为您详细解读该政策的具体影响，并教您如何通过免费更换全新 IP 来避免这笔额外开销。

政策背景：为何会有这次调整？#

据 DMIT 官方通知说明，在过去的一两年中，全球 IP 地址的租赁成本一直在持续上涨。受到市场波动、供应商政策调整以及合同期限的限制，租赁 IP 在长期稳定性和自主掌控力方面存在一定的局限。

为了减轻成本上涨带来的压力，并为用户提供更长期、稳定且可靠的服务环境，DMIT 决定全面转向自购并独立管理 IP 地址的模式。通过自行消化成本，最大程度避免将总体费用转嫁给普通用户。

核心影响：哪些用户需要额外付费？#

虽然 DMIT 启用了全新的自营 IP，但也充分考虑到了部分有特殊业务场景、必须保留现有旧 IP 的客户，因此继续保留了这部分 IP 的使用选项。

  • 受影响的 IP 段：原先分配的旧版 Cogent IP（即 154.x.x.x 开头的 IPv4 地址）。
  • 收费标准：自 2026 年 12 月 1 日起，针对继续保留 154 开头 IP 的产品收取额外的租金补贴费用，标准为每月 1 USD / IPv4。
  • 扣费方式：此项费用将自动附加在您的相关产品账单中。如果后续您不再需要保留该 IP，这项附加费用可以随时同步取消。

应对指南：如何免费更换全新 IP？#

如果您不需要绑定特定的旧 IP，或者更倾向于使用 DMIT 自主掌控的全新 IP 地址，您可以随时完全免费、无门槛地申请变更 IP 地址，以避免产生这笔额外费用。

操作步骤#

  1. 登录您的 DMIT 产品控制面板。
  2. 进入您当前正在使用的 VPS 实例（特别是 154 开头 IP 的实例）详情页。
  3. 点击并切换到 “网络 (Network)” 选项卡。
  4. 在页面中找到 IP 变更选项，手动申请免费更换为全新 IP 地址。

更换完成后，您的实例将分配到 DMIT 全新的自管 IP，后续不再收取每月的附加租金。

总结建议#

这次 DMIT 的底层架构调整从长远来看有利于提升网络资产的掌控力与服务稳定性。虽然对部分需要保留特定 154 IP 的老用户增加了一点成本，但官方给出了完全免费的全新 IP 变更方案。

建议各位持有 DMIT 机器的用户，近期登录控制面板检查一下自己的 IP 地址。如果不必须保留 154 IP，尽早动动手免费更换，以免到了 2026 年 12 月产生不必要的账单扣费。

如需登录并操作更换，可 前往 DMIT 官网控制台 。

常见问题解答（FAQ）#

Q1：我的 IP 不是 154 开头的，会受影响吗？#

+
不会。此次政策调整和附加费仅针对保留旧版 Cogent IP（即 154 开头）的用户。其他段的 IP 不受影响，也不会有额外收费。

Q2：更换 IP 期间机器会断网吗？#

+
变更 IP 会导致网络短暂中断。系统需要重新分配 IP 并更新路由，通常几分钟内即可恢复。建议在业务低峰期进行操作，并在控制面板重启一次实例以确保新 IP 生效。

Q3：现在更换 IP 还需要交额外的更换费用吗？#

+
不需要。本次因政策调整导致的 IP 更换是完全免费且没有任何门槛要求的，您只需在网络选项卡中手动点击申请即可。

Q4：如果我选择不换 IP，费用什么时候开始扣？#

+
如果您维持现状不更换，针对 154 开头 IP 的 $1/月 附加费将从 2026 年 12 月 1 日起自动添加至您的账单中。
